Корневой пакет `bee2go` определяет общие ошибки. Публичные пакеты вызывают типизированные функции `internal/native`; CGo и сырые указатели за его пределы не выходят. Криптографические вычисления выполняет bee2.

## Состояния и память

Объекты с нативным состоянием владеют выделенной C-памятью. `Close` очищает её перед освобождением; повторный вызов безопасен. После закрытия методы с возвращаемой ошибкой выдают `ErrClosed`, а методы стандартных интерфейсов без возвращаемой ошибки вызывают `panic`.

Обычные состояния требуют внешней синхронизации при совместном использовании. Независимые экземпляры могут работать параллельно. Общий RNG синхронизирован внутри библиотеки. Возвращаемые Go-срезы принадлежат вызывающему коду.

Доли BELS сохраняют связь с общими и индивидуальными параметрами. Для сериализации используются `Bytes` и `Parameters`, для импорта — `NewShare` и `NewStandardShare`. `Recover` проверяет соответствие параметров сохранённым метаданным.

## Случайность и обратные вызовы

Операции со случайностью читают 64-байтовую затравку из `io.Reader`, по умолчанию — из `crypto/rand.Reader`. Нативный генератор принадлежит операции или сеансу. `rng.NewWithSource` читает отдельный 32-байтовый вклад для общего генератора. Короткое чтение возвращает ошибку до начала нативной операции.

Параметры сеансов, сертификаты и сохраняемые входные данные копируются в C-память. Обратные вызовы используют `runtime/cgo.Handle`. Валидатор сертификата получает копии данных и возвращает проверенный открытый ключ либо ошибку. Закрытие или повторный вход в активный сеанс из его callback отвергаются.

## Сборка bee2

`scripts/build_bee2.sh` проверяет ревизию и состояние submodule, извлекает закреплённые исходники и применяет [исправления](../patches/README.md). Результат находится в `build/configs/<fingerprint>`; ссылка `build/bee2` выбирает конфигурацию.

Отпечаток учитывает ревизию bee2, компилятор и его версию, тип сборки, флаги, скрипт и содержимое исправлений. Генерируемый `internal/native/build_id.h` связывает кеш CGo с конфигурацией нативной библиотеки.
