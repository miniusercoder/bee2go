# Исправления bee2

Исходная ревизия: `4341f7a5c300f8e6dc292559e671eb899d831433`. Сборка применяет исправления к извлечённым исходникам в `build/`; содержимое patch входит в отпечаток конфигурации.

## `bee2-bauth-challenge.patch`

Терминал BAuth формирует 16-байтовое случайное значение. Шаг токена ошибочно хешировал 24/32 байта при уровнях 192/256, читая за пределами сообщения M2. Исправление задаёт фактическую длину 16 байт и корректирует приоритет условного выражения в двух проверках длины M2. Формат сообщений сохраняется.

Проверки: `btok.TestBAuthAllLevels` и фиксированные C-транскрипты в `tests/integration/`.

При обновлении bee2 исправление нужно перенести на новую ревизию либо удалить, если оно уже вошло в исходники. Применение выполняется с точным совпадением контекста.
